# 테무 시벌롬

이 프로젝트는 테무 발암물질 검출 확인 사이트를 만드는 것 이다.

## 1. 개요
```bash
테무는 상품이 쌉니다. 하지만 위험합니다.
```
- 테무는 전자상거래 플랫폼 입니다.
- 테무의 상품의 90프로 이상이 중국을 생산지로 합니다.
- 해외 직구 방식이기 때문에 제대로 된 안전기준을 통과하지 않습니다.
- 대한민국 정부와 테무가 협력하여 발암물질 기준치를 넘은 상품이 다시 플렛폼에 올라오지 않도록 
AI를 활용해 감시를 시행하고 있습니다.
- 하루에 테무에서 구입되는 상품은 약 5만개 정도 입니다.
- 우리가 흔히 보는 뉴스에서 발암물질 검출 상품은 세관에서 XRF 같은 검사기를 통해 유무를 확인하고 ICP같은 장치로 정확한 포함 비율을 확인합니다.
- 이 기기들의 가격도 만만치 않습니다(억단위)

## 2. 분석
```
사용자가 불안에 떠는 이유는
자기가 쓰고 있는 물건이
안전한지 알 수 없기때문입니다.
```
- 정부는 검사결과를 소비자 24에 올리지만 접근성이 너무 떨어집니다
- 상품코드로 조회가 가능하고 
그마저도 다른 스토어에서 파는 다른 공장에서 만든 상품일 수 있습니다.
- 정부가 1차적으로 필터링 하지만
그것은 완전하지 않고 이미 집에 온 상품을 검사하는 비용은 상품가격보다 휠씬 높습니다.
- 검사를 해보기 보단 버리는게 낫습니다.
- 발암물질의 부작용은 사람마다 적용되는 시기와 정도가 다릅니다. 조용히 몸을 망치고 있을지도 모릅니다.

## 3. 계획
``` 
테무를 안전하게 쓸 수 있게 해주는 all in one 플랫폼 개발
```

- `MySql` 로 `소비자 24`의 데이터 정리
- 실제 `판매 상품명`, `제품번호`, `판매 상품 소개`, `판매 스토어 정보`, `상품 가격` ,`상품 사진` ,`원산지` ,`상품 후기` 정보를 저장한다
- 실제로 특허가 나 있는 기술을 활용한다 
- 각 스토어에 ` 스토어 신뢰도 점수`를 주고 그 스토어 전체 상품에서 발암물질이 검출된 적이 없고 검사기록이 있으며 후기에서 특별한 문제점이 없는 스토어를 추천한다
- 계산과 추론은 AI 모델을 만들어 사용한다.
- 서버비와 토큰비 회수는 결과를 출력받을려면 돈을 지불해야하는 방식으로 만든다.
- 쿠팡의 상품 링크를 붙여넣으면 검사해주는 기능도 넣는다.

| 기능 | 구현 방법 |
|---|---|
| `스토어 신뢰도 점수`| DB와 AI 연결|
| `AI 추론 모델` | 특허청 참고|
| `사용 데이터 수집` | 테무 APP 데이터 크롤링|
| `결제 시스템 구축` | x402, phantom 연결|
